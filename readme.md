# Snake Game! 🐍

## How To Have Fun? 🎆

Download the latest released version of Snake Game. Run `./SnakeGame` directly and have fun! 😀

![Game Demonstration](https://github.com/KONY128/SnakeGame/raw/master/altRes/Demonstration.gif)

## Highlight 👅

- **Up to 3 local players**
- **AI snake** 🐍
- Various types of food, penalties, and **super potions**
- **Player input stack** -- your gameplay will feel extraordinarily smooth
- A random-wall game mode
- Local ranking system
- Multiple game modes
- Delicate graphics and immersive sound effects
- Fully customizable side walls, game speed, and map size
- Invalid input handling

### What Elements Do We Have?

If players crash into each other, they all die.

- Watermelon 🍉 : +1000 to your score
- Pineapple 🍍 : +800 to your score
- Strawberry 🍓 : +400 to your score
- Apple 🍎 : +100 to your score
- Bomb 💣 : clears your score
- S**t 💩 : -1000 to your score
- Rebirth Potion <img src="https://github.com/KONY128/SnakeGame/raw/master/Images/Food/Potion_purple.png" width="25"/> : turns the snake back into a baby snake
- Halved Potion <img src="https://github.com/KONY128/SnakeGame/raw/master/Images/Food/Potion_red.png" width="25"/> : cuts the snake into two pieces
- Food Potion <img src="https://github.com/KONY128/SnakeGame/raw/master/Images/Food/Potion_green.png" width="25"/> : free food rains all around
- Golden Potion <img src="https://github.com/KONY128/SnakeGame/raw/master/Images/Food/Potion_golden.png" width="25"/> : increases the snake's score gain for a limited time
